Rent-Ready Inspection — First Test Version

This ZIP is a prototype, not an installed Android app.
To install as a web app, it must first be hosted at a secure HTTPS address; then open that address in Chrome on your phone and choose Install app / Add to Home screen.

Includes property details, photo preview, notes, optional browser voice dictation, manual findings, starter checklist based on your uploaded form, local saving, TXT report, JSON backup, and print.
Does not yet include AI photo analysis, Word export, embedded photos in reports, cloud sync, or exact reproduction of the original checklist layout.
Photos are previews only and are not saved in the draft. Export backups regularly. Use sample data until employer privacy rules are confirmed.
